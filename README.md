## Template base

A pasta `../template/` contém o Edumin (DexignLab) intacto. **Não altere.**  
Use como referência visual e copie componentes/telas para `src/`.

Alias no editor: `@template/` → `../template/src/`

## Desenvolvimento

```sh
npm install
npm run dev
```
